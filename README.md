# partout-web

PartOut web presence: Hugo static site, Flutter web deploy recipes, and brand assets.

- Hugo site lives here; the Flutter web app is built from `partout-app`.
- Branches: `po-web-*`. Workers commit, never push; po-boss reviews/merges/pushes/deploys.
- See `PARTOUT_WEB_PROPOSAL.md` in the `benthic-io` workspace for scope and phases.
